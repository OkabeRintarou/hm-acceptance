# Team demo

A Helmsman squad works as a small team led by one agent. The leader breaks the task into clear pieces and delegates each piece to a member agent. Squad members work on the same task and branch, so their changes come together in one shared workspace. Each member handles their assignment and reports the result, including any questions or blockers, to the leader. The leader reviews the members’ work, resolves any remaining gaps, and completes the task. This lets the squad divide effort while keeping one agent responsible for the final result.
